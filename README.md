# Список задач (To-Do List)

Простое веб-приложение для управления задачами на **Python + Flask** в фиолетово-чёрной тёмной теме. Задачи хранятся в SQLite, поэтому не пропадают после обновления страницы.

## Возможности

- Создание новых задач
- Отметка задач как выполненных (и снятие отметки)
- Удаление задач
- Сохранение задач после перезагрузки страницы (SQLite)
- Счётчик и индикатор прогресса выполнения
- Валидация: пустые названия и названия длиннее 200 символов отклоняются
- Адаптивный интерфейс (десктоп и телефон)

## Стек

- Backend: Python 3, Flask, SQLite (модуль `sqlite3`)
- Frontend: HTML, CSS, JavaScript (без фреймворков), работа с API через `fetch`

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

База данных `todos.db` создаётся автоматически при первом запуске. Путь к ней можно изменить переменной окружения `DATABASE_PATH`.

## REST API

| Метод  | URL               | Описание                                  |
|--------|-------------------|-------------------------------------------|
| GET    | `/api/tasks`      | Список задач                              |
| POST   | `/api/tasks`      | Создать задачу, тело: `{"title": "..."}`  |
| PATCH  | `/api/tasks/<id>` | Изменить статус, тело: `{"done": true}`   |
| DELETE | `/api/tasks/<id>` | Удалить задачу                            |
